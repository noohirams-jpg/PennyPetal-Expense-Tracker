# 🌸 PennyPetal – Expense Tracker

**Track your money. Watch your savings bloom.**

PennyPetal is a personal expense-tracking web application designed to make everyday money management simple, organized, and visually enjoyable.

## ✨ Features

- 💰 Track daily expenses
- 🧾 Add and manage transactions
- 📊 View spending insights
- 🎯 Manage budgets
- 👛 Organize different wallets
- 🏷️ Manage expense categories
- 📅 Monitor monthly income and spending
- 📱 Responsive and mobile-friendly interface
- 🌸 Clean and friendly visual design

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- HTML
- CSS

## 🎨 Project Goal

The goal of PennyPetal is to create a simple and approachable way to keep track of personal finances without making expense tracking feel complicated.

## 🚀 Project Status

PennyPetal is currently under development, with plans for further improvements and additional features.
